# Extensiones de Ciberip

## Descargas directas (ZIP)

- **[Descargar Aviso IA](https://github.com/Ciberip/Extensiones/raw/refs/heads/main/Descargas/Aviso-IA.zip)**
- **[Descargar Auto Sigue](https://github.com/Ciberip/Extensiones/raw/refs/heads/main/Descargas/Auto-Sigue.zip)**

Los ZIP contienen cada extensión por separado, sin incluir las demás. Se regeneran automáticamente cuando se modifica su carpeta.

## Instalación en Chrome o Edge

1. Descargar el ZIP elegido y descomprimirlo.
2. Abrir `chrome://extensions` (o `edge://extensions`).
3. Activar el modo desarrollador.
4. Pulsar **Cargar descomprimida** y seleccionar la carpeta extraída con `manifest.json`.
